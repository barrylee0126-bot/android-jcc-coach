## 来源混用和数值冲突

资料站的元数据声明，其英雄、羁绊及符文图鉴参考了国际服 tactics.tools，装备、仙灵目录等参考国服官网资源；各条字段来源和国服适配情况无法逐一核实。因此英雄、羁绊和符文应视为**可能混入国际服资料的第三方参考**，所有类别也都需要与游戏内核对。

已抽查到实际不一致：

- 月华神女羁绊描述写伤害减免 7%；18.5 转载公告写 7% → 5%。
- 墨菲特同一条英雄记录的 `skill` 写护盾 700/850，`skillDetail` 写 735/885；公告转载为 700/850 → 735/885。崔丝塔娜的这两个字段亦分别保留了旧值和新值。
- 花仙子、迅捷射手和拉露恩技能描述也与 18.5 公告转载存在差异。详细见 `待核查_数据冲突.json`。未对全部条目做版本校验。

246 条符文记录仅有 **211 个不同 ID**，28 个 ID 被多条记录使用，共多出 35 条；例如“弈子配送”“弈子配送+”“弈子配送++”使用同一 ID。这不必然表示记录错误，但后续不能只按 `id` 建唯一索引或去重，须保留各名称及版本，详细见覆盖统计。英雄、羁绊、装备在该快照内的 ID 均无重复。

数据站对某些资源标注了官网地址；目标资源主机的 robots.txt 禁止 OpenAI 自动抓取，因此本次未保留通过该主机取得的资源文件，也未绕过限制。上述资料均由允许访问的第三方页面公开内容解析，未运行第三方代码、未启动对局。

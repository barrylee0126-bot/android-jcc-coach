# 本局可复查回放页 v1

实现入口：`src/jcc_match_review/`。只读消费明确固定的本机录像抽帧和完成报告，生成自包含 HTML；不接设备、不运行 OCR、不修改标注、不发布局面或建议、不产生动作。

## 复用与最小缺口

先审查 17A `jcc_replay_demo` 和 11F 私有标注界面。17A 已有静态 HTML、转义、严格 CSP、源摘要连接和容量消费校验。其 `load_profile/load_source` 只接受固定四帧、冻结工作区与清单、quarantine/draft 且标签全未知的历史样本；本局抽帧没有该工作区合同。11F 则需要 SampleStore 及可写标注服务。伪造工作区或改变截图来源声明都会掩盖这一缺口。

因此保留既有合同，独立增加本局完成报告的只读适配层：

- 复用 17A 的 `render.CSP/STYLE/esc/reason_text` 和 `integrations.match_capacity`，不重写容量数值、倍率冲突和 ROI 合同。
- 新增私有输入清单、完成依赖门控、录像时间/图像摘要绑定，以及“机器候选／Agent 目视／缺失”的展示。
- 原图及每个局部都来自本次实际核验的图片字节；局部在渲染时重新裁切。不同报告通过源 SHA 连接，不能靠列表顺序或相近时间拼接。
- 不放松截图专用经济适配器。录像抽帧仍是 `video_frame`；历史探索的来源错误必须显示为限制，不能冒充视频到建议闭环。

## 输入与输出

```sh
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m jcc_match_review --manifest /absolute/private/manifest.private.json
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest discover -s src/jcc_match_review/tests -v
```

清单版本 `match-review-v1`，用途 `private_match_review_only`，源类型 `recovered_recording_development`。私有清单显式列出有限文件及其 SHA、录像、帧、案例、报告和时间依据，不使用递归扫描、glob 或自动发现。真实路径、原图、实际摘要、ROI、OCR 原文和浏览器截图只存于项目外受限目录。

先读取 20A/20B 的明确 idle/completed 快照，之后才读取其完成材料并固定摘要；活动、缺失或错误状态拒绝。快照证明冻结时所见的任务状态，不能认证报告正确或阻止同一用户之后改文件。清单及消费文件生成前后重新读取并核对，发生变化拒绝。

每次创建新的 0700 运行目录，文件 0600，拒绝已有输出、符号链接、硬链接、非本人文件、公开权限、Git/项目路径、已知云同步路径以及输入/输出重叠。它保护本工具的读写边界，不是同一用户恶意进程之间的隔离机制。

完成目录包含：

| 文件 | 内容 |
| --- | --- |
| `report.html` | 原画、局部、时间、候选/目视/未知、拒绝原因和证据摘要；直接以本机文件打开 |
| `review.private.json` | 与页面对应的结构化开发观察，所有条目保留源摘要和权限界限 |
| `sources.private.json` | 实际消费的文件白名单、私有路径和完整摘要 |
| `summary.json` | 固定状态与数量，不含私人图片、源路径或数值答案 |
| `COMPLETED.json` | 页面与结构化结果的摘要；最后写入的完成标记 |

## 展示与权限界限

本次完成报告的适配器只识别固定合同，不是通用报告解析器：20A 必须能由完成标记连接到结果、配置、观察、选帧清单和录像摘要，并验证同帧局部像素摘要；20B 必须连接完成标记、配置、源帧索引和结果，校验实际图片摘要与解码时间。任何错配直接拒绝，不凭文件名、数组下标或相近录像时间补接。

20A 交付的是原尺寸局部保留画布，必要区域之外主动置黑；页面说明这一处理，不能把黑色排除区解释成游戏遮挡。20B 的金币探索结果中存在把录像帧声明为 `screenshot` 的来源错误，本页显示 `upstream_capture_kind_mismatch`，不消费其金币算术或经济建议。20B 容量窗口则逐帧消费；中间拒绝帧保持 `null`，不沿用上一帧值。

至少保留早、中、晚实际案例；有可复核价值的前后窗口按各自真实帧、时间和证据展示。不同帧只能说明可见变化，缺少操作录制或决策意图时不推断动作原因。时间分开标记 FFmpeg 请求时间和可用的解码 PTS，不把请求时间声称为精确帧时间戳。

容量同时展示原始拒绝和同帧扩大 ROI 的开发结果；明确框选在看过失败后进行，不能当作盲验。遮挡来自上游 Agent 声明时，直接标明程序没有自动识别遮挡。未知数值为 `null`，不以 0、满编、等级或上一帧补值。阶段/棋盘归属/规则/可操作性缺少独立证据时仍未知。

纯转写、物体外观、同帧多倍率一致和金币算术都不成为人类真值、实际商店价格、可上场棋子、实战建议或自动操作。页面固定 `human_ground_truth_count=0`、`independent_review_count=0`、`accuracy=null`、`advice_eligible=false`、`automatic_action=null`。Agent 目视始终明确单列；不得填成人工标注或不同人员复核。

## 离线与验证

HTML 无脚本、外链、外部图片/字体、网络请求、遥测、表单、框架和服务。原图使用 data URI，导航只有页内锚点，所有报告文本转义。CSP 复用 17A 的 `default-src 'none'`，只允许内嵌样式和 data 图片。

图像含私人对局信息且未脱敏，整份报告留本机。处理时延只描述离线试验，不是实战成绩；未测端到端显示、人的接收、动作成功率或上分效果。

合成测试覆盖来源错配、跨帧观察/裁切、输入被修改、未知却带数值、遮挡覆盖伪成功、容量 ROI/配置/修订拒绝、隐私权限及无联网资源。真实生成另检查固定材料未变、本机浏览器能打开、图像完整加载、案例锚点和表格可读；这些检查不等于人类验收或识别准确率。

本次私有交付为 9 帧、6 个案例、27 张原画与局部图。25 项合成测试通过；本机浏览器实际加载全部图片，页面无脚本和外部资源、索引锚点有效，已查看同帧 ROI 对照及拒绝帧窗口。实际入口、固定材料清单和核验记录见专属交接文档 `资料/开发/21A_本局可复查回放页.md`。生成器拒绝覆盖既有目录；重建时须复制私有清单并指定新的私有 `output_root`。
